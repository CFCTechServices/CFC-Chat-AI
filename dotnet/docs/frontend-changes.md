# Blazor frontend for the .NET migration

The deployable frontend is the Blazor Interactive Server app at `dotnet/src/CFC.ChatAI.Web`, not the tests at `dotnet/tests/CFC.ChatAI.Web.Tests`. Run and publish it with its matching API using the [IIS guide](../../deployment/DOTNET-IIS.md). `web/` and the legacy Python deployment are retained separately.

- **Authentication**: Blazor uses the API for public auth config, invitation checks, password-reset requests and user profile verification. The browser talks directly to Supabase for credential entry and password changes. The Web server forwards the verified access token on individual API requests; provider secrets remain with the API service.
- **Chat and history**: the .NET API handles sessions, messages and feedback. Blazor resolves supported private document image paths with the current user's token and renders the short-lived signed URL, not the loopback API route. Older supported paths in citations/history can still be resolved; invalid legacy storage metadata is not repaired by deployment.
- **Admin**: document uploads send one multipart file per .NET request. See the [upload contract](admin-upload.md) for availability and receipts. Video upload, Python Swagger, and operator ingest routes are not exposed in the UI. Document replacement must preserve the original ID and format. The API controls authorization and enforces upload limits.
- **Optional writes**: Settings and Admin honor `/api/auth/config` flags for profile editing, account lifecycle and permanent deletion. Leave them off until the [profile security gate](plan/supabase-profile-self-service-security.md) and relevant [account checks](complete/internal-api/internal-api-remaining-endpoints-delivery.md) pass.

Use the [route inventory](plan/routing-and-hosting-routes.md) for contract/routing changes. Local component, HTTP and staging checks are not evidence of live Supabase grants/RLS, Storage metadata, or IIS behavior. Before switching traffic, smoke-test the published site against disposable non-production providers and log which write paths were not exercised.
