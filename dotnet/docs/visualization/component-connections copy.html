Boundaries worth noticing

ChatService has no connection to DocumentHandler. DocumentHandler independently ingests documents into the stores; when handling a chat message, ChatService searches existing indexed content through Feedback. Pinecone and Supabase do not call one another or application components. DocumentProcessor and VideoProcessor are independent; only DocumentHandler orchestrates them for ingestion.
